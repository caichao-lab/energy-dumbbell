## 📦 开源项目简介


本项目是国内稀缺、面向LLM打造的**营销决策推理智能体框架**，快速对接大模型构建商业诊断智能体。为能量哑铃营销体系V6.2历史归档开源版本。

【定位区别】：区别于市面上单纯文案生成类营销AI资源，仅靠零散提示词、单一角色指令、通用营销理论，大模型黑盒推理架构，输出结果易受模型幻觉自由度发挥影响，容易产生漂移越界且推理结果难溯源等薄弱环节，本开源项目采用一套**独立原创、经过多轮迭代**的独特结构化规则推理为核心，靠多条规则约束指令，搭配内置固化的营销导图模块策略交叉拆解组合，利用大模型量化检索加辅助推理，实现商业营销决策自动化权重层次输出。属于自研完整动态辩证商业推演体系，且结果可完整溯源。

【内核文件】：搭载独立原创的**运行体、闲置体、能量哑铃结构模型、酒杯模型、内外双因干扰因子、结合问题策略双列表推理架构、利润调节阀模型**等信息内容为核心（以上为 V6.2 核心模型），完整覆盖：产品、客户、成交、利润、闲置资产激活、策略池匹配整套营销推理链路。聚焦商业问题诊断，可以帮助中小微企业店铺老板，处理日常遇到常见营销问题疑难痛点难点，输出针对性且科学合理有利于改善运营的策略指导文案，有效降低企业的营销成本。


### 核心包含内容
1. 多版本迭代思维导图（1.0 ~ 6.2 完整演化链路）
2. 营销专业术语中英对照表 `Term_Glossary.md`
3. 标准化指令库、规则库、术语库全套文档
4. 大量真实商业推演案例素材
5. 策略体系：常规稳健策略 + 破局激进策略双路线逻辑
6. 极简 Python Demo，作为框架接入大模型参考示例

### 能力特点
1. 支持多问题输入，内置主次问题权重判定逻辑
2. 输入商业问题，自动输出主策略 + 关联配套策略
3. 约束大模型输出边界，降低无限制幻觉风险
4. 框架可不断扩充知识库，持续拓展适用场景

### 2. 版本演化溯源
体系前身始于自创《商神营销学》以及《科学的销售》系列，历经多轮迭代后更名能量哑铃营销体系。其中V6.2持续采用规则推理核心框架，仅供测试、调试、学习研究。初代V6.2可用版本存在策略覆盖不足，闭环推理薄弱等短板，典型如输出策略无权重分级，诊断输入端衔接不完善等，直接落地商用AI系统，需谨慎甄别输出。

### 3. 文件夹使用分级提示（src目录内）
- `顶层体系概述`：人工阅读理论，不可导入AI
- `AI推理库`：全套标准AI推理素材，深度二次开发使用
- `迭代规则素材库`：开发草稿，逻辑未校准，禁止正式诊断
- `开发&运维手册`：版本迭代规范，面向开发者
- `历史版本备份存档`：V6.1旧版，仅溯源，禁止商用

### 4. 使用文件选择建议
- 深度二次开发：`src/AI推理库/` 完整加载包（规则最全）
- 新手快速上手：`dist/01_core/` 内的 `6.2纯净版完整加载包(单文件_新对话首条).md`
- ⚠️ 请勿混合使用不同来源的启动包，规则校验标准存在差异

## 🚀 三种诊断模式：1. 完整诊断模式  2. 精简诊断模式 3. 电商诊断模式

 1. **完整诊断模式**：首次使用默认进入完整诊断模式，会引导您填写经营信息。口述或手动输入详细店铺情况完整描述，完整诊断模式开始。

 2. **精简诊断模式**：在问卷采集环节，如果暂时无法提供具体经营数据，不想逐项回答问卷，用户可以输入“跳过”、“不填”、“直接分析”、“快速模式”等关键词，立即终止问卷，系统将跳过问卷，基于现有信息快速生成诊断。

 3. **电商诊断模式**：如果你是电商客户，可直接输入“电商模式”切换到电商诊断模式，输出电商适配策略方案输出。

 4. **诊断报告输出** ：完成诊断分析后，输入“报告”可合并输出十分详细的完整报告内容。
