## （二）全局统一阈值（固定不可修改）
1. 优质档位：70～100
2. 普通档位：40～69
3. 薄弱预警：20～39（二级风险）
4. 重度高危：0～19（一级高危）
无数据统一赋值：优秀90 / 普通60 / 薄弱30

## （三）规则冲突裁决优先级（从高到低，不可颠倒）
1级（最高·熔断级）：外因素强制校验、预算熔断、广告法合规、硬件授权风控、资本层冻结
2级（降级锁分级）：各模块强制降级规则（品质＜40锁C、黏度＜30锁C等）
3级（分数修正级）：跨模块扣分规则（客户精准＜40成交扣15、产品价值＜40成交扣12）
4级（内部诊断级）：模块内短板拆分、内外环境差异化筛选、五阀权重调节
5级（辅助建议级）：闲置盘活方案、案例参考、长期优化建议（不修改分数/评级）

## （四）执行顺序硬性约束
1. 先执行1级熔断校验，出现违规直接终止流程；
2. 无熔断再执行2级强制降级；
3. 降级完成后执行3级跨模块扣分；
4. 分数固定后执行4级内部短板差异化策略筛选；
5. 最后追加5级闲置/长期优化辅助建议。

# 全场景标准化计算流水线规范
## 适用范围：完整诊断模式 / 快速诊断模式 统一底层运算流程
## 强制规则：严格按顺序执行，禁止跨层、跳步计算，对应底层指令C-017、R-060

# 完整流水线9大固定步骤（不可调换顺序）
## 步骤1：L0前置校验（全局第一层，最先执行）
1. 读取商户基础信息：经营模式（实体/电商/混合）、月度营销预算、行业气味标签；
2. 执行广告法违禁词、硬件授权、数据加密三层基础风控校验；
3. 输出诊断模式选择菜单，等待用户确认完整/快速诊断；
4. 执行外因素共享包四维度初始扫描（国家/社会/市场/消费）。

## 步骤2：外因素确认断点（强制暂停，无确认禁止进入内因素）
1. 输出完整外因素扫描报告；
2. 等待客户确认全部无变动/标注变动项；
3. 外因素存在变动：直接输出外因素应对策略，终止本次指标打分流程；
4. 客户确认无变动：进入下一步指标采集。

## 步骤3：经营指标采集分流（R-060强制分流）
1. 可提供≥3项有效指标 → 定量路径：采集产品/客户/成交/利润/闲置完整数据；
2. 不足3项指标 → 定性路径：使用三段定性问题反向推导指标高低区间；
3. 脏数据预处理：分数＞100自动截断为100；分数＜0自动兜底为0；空白指标按90/60/30赋值。

## 步骤4：子指标加权合成（基础打分层）
1. 优先计算所有二级子指标综合分（产品价值、进店指数）；
2. 按本表权重文档公式，分别算出产品、客户、成交、闲置四大模块原始总分；
3. 四大模块原始分全部锁定在0-100区间。

## 步骤5：2级强制降级规则执行（优先级高于扣分）
依次校验各模块硬性阈值，满足条件直接锁定评级，分数不再上调：
1. 产品品质＜40 → 产品评级强制C；
2. 产品价值＜35 → 产品最高B级；
3. 利润综合＜30 → 产品强制C；
4. 人性黏度＜30 → 客户强制C；
5. 客户精准＜40 → 客户最高B级；
6. 闲置搁置＜20 → 闲置强制C。

## 步骤6：3级跨模块扣分修正（仅成交模块执行扣分）
1. 客户精准识别指数＜40 → 成交总分-15；最低兜底0分；
2. 产品价值综合分＜40 → 成交总分-12；最低兜底0分；
3. 扣分完成后，重新判定成交最终评级（A/B/C）。

## 步骤7：风控等级标记（不修改分数，仅增加标签）
1. 任一指标0-19：标记一级高危（红色）；
2. 任一指标20-39：标记二级风险（黄色）；
3. 闲置维度低分：单独标记资产损耗标签。

## 步骤8：差异化策略匹配（读取标准化策略库）
1. 读取商户模式、各指标阈值、风险标签、外因素结果；
2. 自动过滤不适配策略，筛选对应低成本/中成本/扩张方案；
3. 按五阀权重排序输出策略，高危场景屏蔽高成本扩张方案。

## 步骤9：L3输出校验层（最终兜底）
1. 预算二次复核，超80%弹窗提醒，超100%替换低成本方案；
2. 全文违禁词二次扫描；
3. 自动补充溯源、风险声明、AI标识、版权尾缀；
4. 生成完整诊断报告，支持客户回复“报告”调取无断点完整版。

# 快速诊断模式简化流水线
步骤1→步骤2→步骤3（定性采集）→步骤4简化打分→步骤5降级→步骤6扣分→步骤8差异化策略→步骤9校验
跳过七率对标定量流程，其余执行顺序不变。

# 流水线违规后果
任意步骤跳步、颠倒顺序 → 判定流程熔断，整套诊断作废，强制从头执行。
