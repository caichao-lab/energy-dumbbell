# 表3 使用校准说明
1. 数据来源：完整基于能量哑铃6.2 AI专用导图全层级节点生成，所有通用落地策略、适配场景均提取导图原生逻辑；
2. 可人工调整内容：
   ① 案例库ID：全部空白，按你的案例编号手动填充；
   ② 通用基础落地策略：可自行删减、细化、补充行业专属差异化打法（餐饮/零售/美业等）；
   ③ 适配场景：可按需新增细分行业场景标注；
3. 固定不可改动字段：序号、节点编码、6.2标准节点名称、同义术语表编号、跨模块关联编码（已匹配前两张底层表，改动会破坏AI推理映射关系）；
4. 备注字段规则：自动标注冻结模块、专属启用场景，可按需补充自定义业务备注；
5. 推理链路完整闭环：术语表统一名词 → 关联映射表约束模块联动 → 本表调取标准化落地策略，直接导入大模型做标准化经营方案推理。
