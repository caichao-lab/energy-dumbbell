# 能量哑铃营销体系架构图（6.2版）

> 体系版本：6.2
> 更新日期：2026-07-21


## 一、体系总述（完整世界观）

能量哑铃营销以能量体（外层：资源整合+资源配置）和哑铃体（内层：运行体五大模块+闲置体）两层结构为骨架，以**想**（主导）、**钱**（辅助）、**做**（辅助）三股显性主线为表层连接机制，以**市场供求**为隐性引线贯穿全程。

运行体（一级哑铃结构）呈哑铃状分布，形态稳定、边界清晰；闲置体（二级哑铃结构）呈星云状分布，附着于运行体各模块周围。

外因素共享包独立存在，各模块调用时使用“模块前缀+外因素”格式。6.2版本在外因素共享包-社会因素下新增灰色生态分支（政企渠道灰色操作/区域性不良营商环境/行政资源恶意打压），仅识别不策略化，配套R-137/R-138/R-139规则熔断与脱敏。

资本层和股权层冻结跳过。资源复制模块仅当客户明确表达扩张意图时触发。

**推理入口：资源配置层 → 运行体/闲置体 → 四大模块 → 问题/策略层，深度4-5层。**

> **资源是经营对象，诊断是测量工具，哑铃是运转结构，调节阀是控制手段，绞索是连接机制。**


## 二、立体思维同步原则（理解架构图的阅读指南）

在与客户沟通诊断和解决问题的过程中，我们不是向客户“讲解”平面导图，而是把客户的思维“带入”立体的能量星球场景。

当客户与我们在同一个立体空间中看见：
- 产品、客户、成交、利润、闲置的位置关系
- 四股绞索的绞合结构与伸缩方向
- 五大模块之间的流动牵引关系

沟通的摩擦大幅降低，决策的速度大幅提升。

**立体思维同步，是营销策划高效沟通的基础前提。**

## 四、推理路径概览

```
客户提出经营问题
        ↓
【外因素共享包强制扫描】
国家因素·社会因素·市场因素·消费因素
（6.2新增：社会因素-灰色生态识别）
        ↓
外因素有变化 → 优先应对外因素（结束）
外因素无变化 → 进入资源配置层
        ↓
【资源配置层】
├── 运行体（一级哑铃结构）← 默认优先
│   ├── 产品模块 → 产品指标→产品问题→产品策略
│   ├── 客户模块 → 客户指标→客户问题→客户策略
│   ├── 成交模块 → 成交指标→成交问题→成交策略
│   └── 利润模块 → 利润指标→利润问题→五阀策略
└── 闲置体（二级哑铃结构）← 闲置多时优先
    ├── 闲置产品 → 调用运行体·产品·吃相/卖相 → 清仓/置换
    ├── 闲置客户 → 调用运行体·客户·识别过滤 → 共享/出租/转让
    ├── 闲置成交 → 调用运行体·成交·支付方式 → 出租/共享
    └── 闲置利润 → 联动运行体·利润·五阀 → 闲置输出
```
