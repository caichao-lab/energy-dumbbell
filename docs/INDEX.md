Energy Dumbbell Marketing System V6.2 | Global Index Document

> ⚠️ 重要提示
> 仓库文档分为三层目录，**搭建营销智能体无需加载全部文件**，按需选取即可。
> Core为运行必需；Cases为增强素材；Archive属于历史资料，推理时不必载入。

## 四层仓库分区说明
1. 01_core + 02_cases｜基础运行层
构建营销智能体最小必备文件，新手直接加载使用。
2. main-v6.2-docs｜完整深度理论层
全套完整版架构、规则推导原始文档，适合深度研究、二次重构体系。
3. 03_archive｜历史溯源归档层
旧版本体系、全周期迭代思维导图，仅用于溯源，禁止载入AI推理。
4. demo｜示例演示工具
仅提供知识库加载参考代码，不限定任何开发框架。


## 仓库目录分层说明
### 📁 01_core 【核心推理层 · 运行必须加载】
Mandatory Runtime Core
整套营销决策智能体标准化本体，定稿正式版本，可直接导入LLM、RAG、各类Agent框架
包含：
- 完整启动加载包（系统指令、推理流程、输出规范）
- 全局规则库：模块联动规则、冲突校验、风控约束
- 全域术语库：统一名词定义，消除AI语义歧义
- 原创核心模型文档：外因五层筛子模型、三体模型、内外四力架构、能量哑铃动态模型、利润调节阀模型
- 策略矩阵、问题矩阵、诊断推理标准流程

✅ 使用建议：任何场景搭建智能体，此目录文件优先载入

### 📁 02_cases 【案例推演层 · 可选增强素材】
Deduplication Case Library (Optional)
商业实战推演案例、行业适配矩阵、典型经营矛盾场景样本
覆盖实体门店、电商、私域流量等多类经营场景。

✅ 使用建议：生产环境RAG检索增强，提升落地精准度；不加载也可正常运行基础推理

### 📁 03_archive 【历史归档层 · 仅溯源研究，禁止用于推理】
Historical Archive (NOT FOR INFERENCE)
体系全周期迭代资产，**请勿载入大模型进行决策推演**
包含：
- V1 ~ V12 多版本演进思维导图
- V5.4、V6.1旧版完整体系存档
- 架构迭代草稿、废弃方案、历次调整记录、模型演化对比资料

✅ 使用建议：面向理论研究者、体系二次开发人员查阅历史思路

### 📁 demo 【演示代码文件夹】
Demo Scripts
极简Python参考脚本，仅演示知识库接入大模型的实现方式。
> 重要：Demo仅作为学习示例，不限定开发框架，不具备生产环境容错能力。
> 你可以使用 Dify、FastGPT、LangChain、本地大模型等任意载体加载本知识库。

## 三种使用者推荐加载方案
1. 新手快速部署营销智能体
加载范围：`01_core` 全部文档

2. 开发者搭建生产级商业诊断AI
加载范围：`01_core` + `02_cases`

3. 理论研究者、想要二次迭代优化体系
浏览范围：`01_core` + `02_cases` + `03_archive`

## 核心规范
1. 一切智能体推理，以 `01_core` 内文档作为唯一标准依据
2. `03_archive` 内所有内容仅用于溯源，旧规则、旧模型不再生效
3. 禁止混合归档草稿与正式核心规则，避免逻辑冲突
