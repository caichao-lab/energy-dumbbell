# 关于本项目的定位与使用方式（补充说明）

## 重要说明

本仓库**不强制依赖专属运行代码**。

本项目并非可直接部署的软件程序，而是一套原创【能量哑铃营销体系 V6.2】商业推理知识本体（全部 Markdown 文档），也就是营销决策智能体的核心思维框架。

你可以将整套文档导入 **Dify、FastGPT、LangChain、任何本地大模型、自研 Agent 程序**等任意载体。市面上成熟的 LLM/RAG 代码框架均可作为运行容器，无需限定单一代码实现。

本仓库重心：持续完善**商业推理规则、模型理论、策略库、术语库、推演案例**；运行载体、交互界面、接口调度代码，使用者可根据自身技术栈自由选择、自主开发。

---

## 演示代码 Demo

根目录 `/demo` 文件夹提供极简 Python 脚本，演示加载知识库对接大模型的基础方式。

再次强调：**Demo 仅为示例，不限定任何技术栈。**

生产环境推荐使用成熟 RAG 平台：

- [Dify](https://github.com/langgenius/dify)
- [FastGPT](https://github.com/labring/FastGPT)
- [LangGraph](https://github.com/langchain-ai/langgraph)
